# The Corbitt Files

A play aid for **Call of Cthulhu 7th Edition Quick-Start** and the introductory
scenario *The Haunting*, built for a table with a blind player.

Everything is one self-contained `index.html`. No build step, no dependencies,
no network requests.

## Player side

Designed for **iPhone VoiceOver**. Announcements go through ARIA live regions
rather than the Web Speech API, so they are spoken in the reader's own voice and
rate, and every control is a real labelled button reachable by swipe.

- Four ready-made investigators, with Regular / Hard / Extreme precomputed and
  announced on every skill
- Dice rolling with bonus and penalty dice handled automatically
- Push rolls offered only when the rules allow them
- Hit point tracking with automatic major-wound, unconscious and dying detection
- Sanity rolls that parse the `X/Y` notation and walk the 5+ trauma chain
- All nine handouts as text, including the one that is only a picture in the PDF
- An eleven-step hands-on tutorial for players who have never rolled a die

## Keeper side

- A matching eleven-step script for teaching the game at the table
- **Run the session**: sixteen scenes with read-aloud text, prompts, rolls to
  call for, and outcomes, plus live tracking of handouts, discoveries, and
  Corbitt's hit points, magic points and Flesh Ward
- Every speaking part with a voice, motive, mannerisms and lines
- A printable quick reference, including a half-and-fifth lookup table
